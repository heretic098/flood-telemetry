Hydrological Physics Engine & Telemetry Methodology

This document outlines the real-time data sources, hydraulic physics equations, data provenance confidence tiers, and operational rules governing the Somerset Levels & Moors Flood Monitoring Dashboard.

🌐 1. Open Data Feeds & Server Architecture

The application ingests high-frequency 15-minute telemetry directly from the UK Environment Agency (EA) open API:

📡 EA Flood Monitoring API

Fetches live stage elevations in meters above Ordnance Datum Newlyn (mAOD) across 8 critical gauging stations.

https://environment.data.gov.uk/flood-monitoring/id/measures/{id}/readings

⚡ SQLite Embedded WAL Cache

A background process (server.js) syncs all 8 station measures every 5 minutes into a local SQLite database (telemetry.db in WAL mode). The frontend fetches /api/status for instant < 20ms page loads without waiting for external API calls.

🏷️ 2. Data Provenance & Visual Confidence Badges

To ensure complete scientific integrity, every infrastructure card displays an explicit data provenance badge indicating whether its status is directly measured, physically enforced, or inferred from operational models:

📡 DEDICATED SENSORS HIGH CONFIDENCE

Derived directly from paired physical sensors deployed at the structure (e.g. Monk's Leaze Upstream 52233 vs Downstream Sowy 52234).

⚖️ HYDROSTATIC LAW HIGH CONFIDENCE

Governed by absolute head differential pressure laws (e.g., Dunball Tidal Outfall flap doors where seawater stage exceeding inland drain stage physically forces passive doors shut).

⚡ LEVEL SOP MODEL MEDIUM CONFIDENCE

Inferred from official EA Standard Operating Procedure (SOP) level triggers because public EA telemetry does not expose real-time SCADA electrical pump status.

📐 3. Hydrological & Hydraulic Core Equations

A. Spillway Overtopping & Submergence (Villemonte Weir Model)

Given upstream river stage $h_{\text{river}}$, moor basin stage $h_{\text{moor}}$, and surveyed crest elevation $Z_{\text{crest}}$:

$$H_u = h_{\text{river}} - Z_{\text{crest}} \quad \text{and} \quad H_d = h_{\text{moor}} - Z_{\text{crest}}$$ $$\text{Submergence Ratio } S = \frac{H_d}{H_u}$$
  • SECURE: $H_u < -0.15\text{m}$ (River level is >15cm below spillway crest).
  • NEAR CREST: $-0.15\text{m} \le H_u < 0\text{m}$ (River level is within 15cm of overtopping).
  • FREE OVERTOPPING: $H_u \ge 0\text{m}$ and $S < 0.70$ (Water flows freely over spillway crest into moor).
  • DROWNED / SUBMERGED: $H_u \ge 0\text{m}$ and $S \ge 0.70$ (High tailwater in flooded moor drowns the spillway).
  • REVERSE SPILL: $H_d > H_u \ge 0\text{m}$ (Flooded moor level exceeds river level, spilling back into channel).

B. Submerged Gate Volumetric Discharge Equation

Discharge across Monk's Leaze Clyse into the Sowy Relief Channel is estimated using the hydraulic submerged gate formula:

$$Q = C_d \cdot B \cdot H_{\text{head}} \cdot \sqrt{2g \Delta h}$$

Where $C_d = 0.60$ (discharge coefficient), $B = 4.20\text{m}$ (gate width), $H_{\text{head}} = h_{\text{up}} - Z_{\text{threshold}}$ (Diversion Threshold $Z_{\text{threshold}} = 4.20\text{m}$ AOD; Structure Sill / Wall Height $Z_{\text{structure}} = 6.70\text{m}$ AOD), and $\Delta h = h_{\text{up}} - h_{\text{down}}$.

📡 5. Dynamic Crest History & Future Remote Sensing Innovations

A. Time-Versioned Crest Elevation Engine (crest_history)

Spillway crest elevations ($Z_{\text{crest}}$) are evaluated dynamically using date-stamped configuration records in hydro_config.json. When inspecting historical archives or replaying multi-year flood events, getActiveCrestHeight() matches the telemetry timestamp against effective survey date windows (e.g., pre- vs. post-2014 Baltmoor Wall raising or SRA capacity improvement schemes).

B. Future Roadmap: Automated Remote Sensing (DEFRA LiDAR & InSAR)

To move beyond static SOP manuals, future roadmap iterations will integrate automated external validation pipelines:

  • DEFRA 25cm / 1m LiDAR DTM API: Programmatically sampling ground elevation rasters along spillway vector transects across survey years (1998–present) to derive true minimum crest elevations ($Z_{\text{crest}}$).
  • Copernicus Sentinel-1 InSAR (EGMS): Utilizing Interferometric Synthetic Aperture Radar time-series to monitor millimeter-scale embankment settling and track post-construction bank height modifications continuously.
